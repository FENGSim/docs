**********************
Examples
**********************

To run the modal example: ::
  
  cd FENGSim/starter/ccx/Mesh1
  ./run

The ``pre.fbl`` script runs in CGX to generate an ``all.msh`` file in ``.inp`` format. The resulting ``.gif`` files are saved to ``FENGSim/starter/ccx/Mesh1/Refs``.
