**********************
Build and Install
**********************

* To clone FENGSim: ::
  
    git clone https://github.com/OpenDigitalTwin-Dev/FENGSim.git
  
* To clone MultiX: ::
  
    cd FENGSim/toolkit
    ./multix
  
* To build CalculiX and CalculiX GraphiX: ::
  
    cd FENGSim/toolkit/MultiX/extern/Calculix
    ./install
