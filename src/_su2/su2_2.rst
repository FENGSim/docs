
**********************
Build and Install
**********************

* To clone FENGSim: ::
  
    git clone https://github.com/FENGSim/FENGSim.git
  
* To clone CFD: ::
  
    cd FENGSim/toolkit
    git clone https://github.com/FENGSim/CFD.git
  
* To install SU2: ::
  
    cd FENGSim/toolkit/CFD/su2-8.5.0
    ./install
