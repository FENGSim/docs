**********************
Build and Install
**********************

* To clone FENGSim: ::
  
    git clone https://github.com/FENGSim/FENGSim.git
      
* To compile and install PCL: ::
		
    cd FENGSim/toolkit/Geometry/pcl
    ./install

* To compile and install GDT: ::
    
    cd FENGSim/starter/GDT
    ./install
