
**********************
Build and Install
**********************

* To clone FENGSim: ::
  
    git clone https://github.com/FENGSim/FENGSim.git
  
* To clone DAE: ::
  
    cd FENGSim/toolkit
    git clone https://github.com/FENGSim/DAE.git
  
* To install Cantera ::
  
    cd FENGSim/toolkit/DAE/cantera
    ./install
    ls ../install/cantera_install
