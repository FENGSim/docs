**********************
Build and Install
**********************

* To clone FENGSim: ::
  
    git clone https://github.com/FENGSim/FENGSim.git
  
* To clone PS: ::
  
    git submodule init
    git submodule update toolkit/PS
    
* To compile and install Geant4: ::
		
    cd FENGSim/toolkit/PS/geant4
    ./install
