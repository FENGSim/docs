=======================
Isaac-Sim
=======================

* To download Isaac-Sim: ::
  
    wget https://downloads.isaacsim.nvidia.com/isaac-sim-standalone-5.1.0-linux-x86_64.zip
    
* To run: ::
		
    mkdir ~/isaacsim
    cd ~/Downloads
    unzip "isaac-sim-standalone-5.1.0-linux-x86_64.zip" -d ~/isaacsim
    cd ~/isaacsim
    ./post_install.sh
    ./isaac-sim.sh
