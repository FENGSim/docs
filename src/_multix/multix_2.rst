**********************
Build and Install
**********************

* To clone FENGSim: ::
  
    git clone https://github.com/OpenDigitalTwin-Dev/FENGSim.git
  
* To clone Multix: ::
  
    cd FENGSim/toolkit
    git clone https://github.com/OpenDigitalTwin-Dev/MultiX.git
  
* To build MultiX: ::
  
    cd FENGSim/toolkit/MultiX/
    ./install
