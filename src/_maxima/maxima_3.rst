**********************
Examples
**********************

To run an example: ::

  cd FENGSim/toolkit/DAE/install/maxima_install/bin
  export XMAXIMA_MAXIMA=$PWD/maxima
  ./xmaxima

.. image:: fig/maxima.png
   :scale: 50 %
   :alt: alternate text
   :align: center

To run ``rmaxima``: ::

  cd FENGSim/toolkit/DAE/install/maxima_install/bin
  export PATH=$PWD:$PATH
  ./rmaxima
