**********************
Build and Install
**********************

* To clone FENGSim: ::
  
    git clone https://github.com/FENGSim/FENGSim.git
  
* To clone DAE: ::
    
    git submodule init
    git submodule update toolkit/DAE
    
* To compile and install Hopsan: ::
		
    cd FENGSim/toolkit/DAE/hopsan
    ./install
