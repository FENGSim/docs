**********************
Build and Instal
**********************

* To clone FENGSim: ::
  
    git clone https://github.com/FENGSim/FENGSim.git
  
* To clone Particles: ::
  
    git submodule init
    git submodule update toolkit/Particles
    
* To compile and install ExaCA: ::
		
    cd FENGSim/toolkit/Particles/exaca
    ./install
