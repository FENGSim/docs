**********************
Build and Install
**********************

=======================
Kit-CAE
=======================

* To clone kit-cae: ::
  
    git clone https://github.com/NVIDIA-Omniverse/kit-cae.git
    
* To build: ::
		
    cd kit-cae
    ./repo.sh build -r

* To run: ::
		
    cd kit-cae
    ./repo.sh launch -n omni.cae.kit
