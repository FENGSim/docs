
**********************
Build and Install
**********************

* For compilation details, refer to: `<https://adevaucorbeil.github.io/karamelo/html/GettingStarted.html>`_.
* Dependencies: The ``matplotlib-cpp`` and ``gzstream`` are stored in the directory ``FENGSim/toolkit/MultiX/extern/Karamelo/third-party``.

* To clone FENGSim ::
  
    git clone https://github.com/FENGSim/FENGSim.git
  
* To clone MultiX ::
  
    cd FENGSim/toolkit
    git clone https://github.com/FENGSim/MultiX.git
  
* To compile and install Karamelo ::
  
    cd FENGSim/toolkit/MultiX/extern/Karamelo
    ./install
